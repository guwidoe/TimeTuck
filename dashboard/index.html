Beyond the adapted tests

Measurement notes & reproducibility

What the percentage means

The denominator includes pending and explicitly excluded methods. Exclusions stay visible so the scope cannot silently inflate coverage. A passing adaptation is evidence for that method’s assertions, not a claim that the original JUnit suite runs against Rust.

Keeping results current

The page reloads saved results every 15 seconds; it does not run tests in your browser. Rust checks regenerate this report. Changes to measured sources mark earlier comparisons stale. The timestamp is the last report generation time.
