# Owned configured factories

NativeSolverConfigurationSource owns explicitly parsed XML resources and entity-key registrations. It selects the solver-specific resource property first, the caller-selected global resource property second, then the caller default. A present empty or missing key rejects; selection does not silently fall through. Existing PropertyFallbackRules provide canonical and legacy resolution with live diagnostics.

resolve consumes a native NamedSolverConfiguration template. XML selects registered model/scoring keys and real entity PlanningType identities, and the existing native_termination_plan/with_sequence binder validates the full declaration before transferring owned scalar fields. Runtime spent, unimproved, score and diminished properties then override applicable defaults. Existing explicit native phase diminished policy wins over phase XML, solver XML and runtime defaults. manager_workers selects actual configured manager concurrency (native integer profile 1..128, default 1).

prepare_configured preflights the complete request set before any executable factory builder, including exact ordered registered entity identities. Successful factories own their effective sequences. build_manager creates the existing real manager from the selected factory and resolved worker count; its factory argument must be the factory published for that request. Per-job time overrides retain the factory configuration.

The owned profile preserves supplied static closure/expression references. Solve-wide XML stepCountLimit needs a temporary borrowed expression and therefore rejects here. Call the existing scoped XmlTerminationPlan::with_sequence for that profile. Existing Exact, RuinRecreate and Custom XML projection supports only spent-time scalars and rejects other phase controls before a callback; additive extension APIs are outside this bridge. Phase declarations must match the caller native sequence in number and order.
