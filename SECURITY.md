# Security reporting

TimeTuck is experimental and has no published releases. There is no supported
stable release series or guaranteed security-response time.

Report suspected vulnerabilities privately through
[GitHub private vulnerability reporting](https://github.com/guwidoe/TimeTuck/security/advisories/new).
Include the affected revision, a minimal reproduction, impact, and a proposed fix
if available. Do not include real credentials, private schedules, or unrelated
personal data. Public issues are not confidential reports.

If you discover an exposed credential, notify its owner privately so it can be
revoked or rotated. Removing the current file alone does not remove historical
copies or existing workflow logs.
